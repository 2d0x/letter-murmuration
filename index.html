Letter Murmuration

Every letter on a web page becomes a creature with a body and mass — and flies off in a flock, like starlings.

English · Русский

Open the demoTwelve Shakespeare sonnets. Keys 1, 2, 3 — rest, murmuration, horde. Install the bookmarkletDrag the button to your bookmarks bar — and murmuration works on any site.

All versions

  1. v1

    Letters → boids; Rest / Murmuration / Horde modes; WebGL2 renderer.

  2. v2

    Bodies with volume and mass, true K nearest neighbours, fear of collision.

  3. v3

    The horde goes around on the side, hunting falcon, roost, dot gun.

  4. v4

    Take-off wave from the cursor, settings panel, birds predict the cursor’s path.

  5. v5

    Horde without the “line” and synchronous shaking, birds fly around pictures, giant letters.

  6. v6

    Whole-page bookmarklet, letters wake up as you scroll, landing along an arc.

v1–v5 are kept as they were built, with a Russian interface.
