# Заметки проекта: факты для README

Всё ниже проверено замерами в headless Chromium (программный WebGL, 1440×900). На обычном компьютере с видеокартой кадров больше.

## Что это

Скрипт для браузера: каждая буква веб-страницы становится существом с телом и массой.
- **Мурмурация** — буквы летают стаей, как скворцы.
- **Орда** — буквы бегут к курсору, как толпа зомби.
- **Покой** — буквы стоят на местах. Если провести курсором, вспархивают и садятся обратно.

Исходный вопрос: можно ли поведением стаи из исследований скворцов заменить «прямолинейных» мобов в играх вроде Vampire Survivors и при этом держать тысячи существ. Ответ: да, десятки тысяч в одном потоке JS.
- 7,7 тыс. букв: стая около 10 мс на шаг.
- 26 тыс. букв (×4 текста): стая 30 мс, орда 34 мс на шаг.

## Как запускать

1. **Демо-страница** `dist/vN/index.html` — двенадцать сонетов Шекспира (общественное достояние) с картинками, списками, таблицей и шкалой кеглей.
2. **Закладка (букмарклет)** — `dist/bm/index.html`, страница установки. Кнопку «Мурмурация» перетаскивают на панель закладок, дальше она работает на любом сайте.
   - Скрипт целиком внутри закладки, около 61 КБ (с английским и русским интерфейсом; до перевода было 57 КБ).
   - Повторное нажатие или Esc выключает.
   - Сайты со строгой CSP (Google, YouTube, GitHub) могут не пустить скрипт.
3. **Консоль** — `dist/vN/letters-swarm-console-vN.js` вставляют в консоль DevTools на любой странице.

**Клавиши:**
- `1` Покой, `2` Мурмурация, `3` Орда;
- `V` — тела с объёмом или «призраки»;
- `H` — сокол-охотник;
- `F` — точкомёт;
- `Esc` — выключить (в закладке и консольной версии).

**Панель «Настройки динамики»:**
- базовая скорость орды;
- обзор зомби;
- скорость птиц;
- испуг от курсора;
- число соседей K;
- скорость волны взлёта;
- реакция зомби;
- отступ птиц от картинок;
- скорострельность;
- скорость пуль.

## Как устроено

- **Восприятие.** Каждая буква видит K = 7 ближайших соседей — топологическое правило из наблюдений за скворцами (Ballerini et al., PNAS 2008). Соседи ищутся по равномерной сетке с сортировкой подсчётом. Восприятие обновляется через шаг, по очереди. Птицы в панике обновляют его каждый шаг.
- **Правила стаи.** Расталкивание, выравнивание и сближение по Рейнольдсу (Reynolds, 1987). Плюс заранее уклоняются от столкновения по времени до него (Karamouzas, Skinner, Guy, PRL 2014).
- **Тела.** Это круги с массой по площади буквы. Столкновения разрешаются позиционно, методом Гаусса — Зейделя (как в position-based dynamics для толп, Weiss et al. 2017). У жирного начертания масса выше.
- **Полёт.** Скорость почти постоянная, поворот ограничен (крен). Стая держится над «гнездовьем» в верхней части экрана — идея модели StarDisplay (Hemelrijk, Hildenbrandt). Развороты начинают несколько зачинщиков, и волна бежит по стае (Attanasi et al. 2014).
- **Хищники.**
  - Сокол-охотник атакует сам. Тип ответа стаи зависит от скорости атаки (Storms et al. 2019).
  - Курсор — второй сокол. Птица просчитывает путь курсора на 12 шагов вперёд и уходит с него вбок. Тревога передаётся соседям волной.
- **Орда.**
  - Каждый идёт за соседом впереди: не быстрее него, с запасом по зазору, как в моделях транспортного потока.
  - Если упёрся, обходит сбоку. Сторону выбирает сам, по карте плотности толпы вокруг героя.
  - У каждого своё время реакции. Видит героя с запаздыванием.
  - Крупные буквы видят дальше, но медленнее.
- **Картинки — препятствия.** Птицы облетают их по лучу вперёд (Reynolds 1999), орда обтекает.
- **Рендер.** Все буквы рисуются одним вызовом WebGL2 (instanced quads + атлас глифов); если WebGL2 нет — Canvas2D. Оригинальный текст становится прозрачным, но остаётся в DOM для доступности и поиска.

## История версий

Каждая версия — отдельная папка `vN` и сборка `dist/vN`.

| Версия | Что появилось | Замеры |
|---|---|---|
| v1 | Буквы → боиды, режимы Покой / Мурмурация / Орда, 4 алгоритма поиска соседей для сравнения, WebGL2-рендер | Canvas2D около 100 мс на кадр → WebGL2 |
| v2 | Тела с объёмом и массой, честные K ближайших (вместо «первых найденных»), страх столкновения | Исчезли «стоячие волны» — плотные чёрные скопления |
| v3 | Орда следует за передним и обходит сбоку (ушли «барханы-полумесяцы»), сокол-охотник, гнездовье, точкомёт | — |
| v4 | Взлёт волной от курсора, панель настроек, обзор зомби, птицы предугадывают путь курсора, тестовая страница со ссылками, списками, таблицей, картинками | Рядом с быстрым курсором ближе 25 px: 24,2 → 1,9 птицы |
| v5 | Орда без «линии» и синхронной тряски (убрана общая ось обхода), личное время реакции, птицы облетают картинки, буквы-великаны в 2× и 4× заголовка | Синхронное смещение кольца при скорости 8: 66,8 → 1,8 (частота 2,5 Гц исчезла); птиц у края картинок: 125 → 1,6 |
| v6 | Закладка на всю страницу (закреплённые шапки остаются текстом), при прокрутке просыпаются новые буквы, посадка по дуге, настройки скорострельности и скорости пуль | За 10 с сбито: 101 → 1683 при 240 выстрелах в секунду |

## Сборка и тесты

- `python3 build.py v6` → `dist/v6/index.html` и консольный скрипт.
- `npm install && npm run bookmarklet` → `dist/bm/` (страница установки и `bookmarklet.txt`).
- Тесты — Python + Playwright (`pip install playwright && playwright install chromium`), запускаются из корня, например `python3 tests/test_bm.py`. `tests/mock_wiki.html` — макет страницы в духе Википедии с собственным текстом.

## Ограничения

- На сайтах со строгой Content Security Policy закладка может не сработать.
- На телефоне закладками пользоваться неудобно; демо-страница на телефоне работает, но медленнее.
- Орда не прокладывает маршрут вокруг больших препятствий, только обтекает локально (для этого нужен flow field).
